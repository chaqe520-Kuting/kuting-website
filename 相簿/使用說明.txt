【新增一本法會相簿】

1. 在電腦上新增一個資料夾，名稱用「日期 法會名稱」，例如：
       2027-02-13 玉皇大帝聖誕
   日期寫在最前面（西元 2027-02-13 或民國 116-02-13 都可以），網站會用它排順序並顯示日期；後面的文字就是相簿名稱。

2. 把這次法會的照片放進資料夾（手機照片、LINE 存下來的照片都可以，iPhone 的 HEIC 也可以）。
   - 想指定封面：把那張照片的檔名改成「封面」開頭，例如「封面.jpg」。沒有的話用第一張。
   - 想加一段說明文字：在資料夾裡放一個「說明.txt」，寫上說明即可（可不放）。

3. 用電腦打開 GitHub 網站的「相簿」資料夾，按右上角「Add file」→「Upload files」。

4. 把整個資料夾直接拖進上傳的方框裡，等照片都出現在下方清單。

5. 按綠色的「Commit changes」。

6. 等 3～5 分鐘，網站的「活動相簿」就會出現新相簿。
   GitHub 會自動把照片縮小、轉正方向，並刪除照片裡的拍攝地點資訊。

【修改或刪除】
- 補照片：進到那本相簿的資料夾，一樣用「Add file」→「Upload files」上傳。
- 刪照片：點進那張照片，按右上角「⋯」→「Delete file」，再按「Commit changes」。
- 改相簿名稱或日期：請告訴 Claude 幫忙改資料夾名稱。

【注意】
- 每次上傳最多 100 個檔案，每張照片不能超過 25MB。
- 資料夾名稱沒有用日期開頭的話，網站會略過那個資料夾。
