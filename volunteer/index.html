管理者登入

請用各平台的管理者姓名與密碼登入。本頁會同時連到法會報名、信徒查詢、供品贊助、庫房管理四個平台；如果各平台密碼不同，登入後可以在上方個別補登。

關閉瀏覽器、或 30 分鐘沒有操作會自動登出。請勿在公用電腦使用。
法會報名、信徒查詢、供品贊助、庫房管理四欄是即時從平台讀回來的，在這裡開通、停用會直接改到平台帳號。
財務記帳無法在網頁建立帳號，這欄只是記錄用，帳號仍要到 Firebase 後台建立（見「操作說明」）。本頁不記錄任何密碼。
已開通可以登入 已停用有帳號但不能登入 －沒有帳號 待建立財務記帳尚未建帳號 ｜點格子可開通、停用或重新啟用

開通與停用

  1. 新增志工：按「＋ 新增志工」，填中文姓名、勾選要開通的平台、填預設密碼（至少 8 碼），按「開通」。勾選的平台會立刻建好帳號並啟用。
  2. 加開某個平台：在名冊總表點那個人在該平台的「－」格子。
  3. 停用：點「已開通」格子，確認後該平台帳號立即停用，之前輸入的資料不會刪除。再點一次可以重新啟用。
  4. 預設密碼：請當面或電話告訴志工，並請對方登入平台後自己改密碼。本頁不會留下密碼。
  5. 出現「已關閉網頁建立帳號」：照畫面步驟先到 Firebase 後台建好帳號（Email 會顯示在畫面上，密碼填同一組預設密碼），再回名冊按「再試一次」，名冊會自動補上名單並開通。目前信徒查詢是這樣。
  6. 忘記密碼：平台無法直接重設。請先停用舊帳號，再用加註的姓名（例如「葉懿青2」）重新開通。
  7. 自己的帳號不能在這裡停用，避免把自己鎖在外面。

財務記帳（需手動）

  1. 在下面輸入志工姓名，按「產生登入 Email」並複製。
  2. Firebase 主控台 → kuting-accounting115 → Authentication → 使用者 → 新增使用者：電子郵件貼上 Email，密碼自訂滿 8 碼 → 新增。
  3. 回到名冊，把那個人的財務記帳格子點成「已開通」。
  4. 停用：Firebase 主控台 → Authentication → 使用者 → 該帳號右邊選單 → 停用帳戶，再把格子點成「已停用」。
  5. 一般帳號可以查看、登記收支，但看不到操作紀錄；請不要把志工加為管理者。

注意事項

  • 名冊會用你的管理者身分登入四個平台，請只在自己的電腦使用，用完按右上「登出」。
  • 備註與財務記帳欄存在這台電腦的瀏覽器裡，換電腦請用「下載備註備份」「匯入備份」。四個平台的帳號狀態則是即時讀取，不受影響。
  • 如果某個平台顯示「未連線」，點它可以單獨用該平台的密碼登入。
