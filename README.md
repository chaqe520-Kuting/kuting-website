# 古亭院網站

古亭院的資訊網站：法會行事曆、活動相簿（照片與影片）、佛學知識專區。
網站是純靜態網頁，免費放在 GitHub Pages 上，不需要資料庫或主機。

## 網站有哪些頁面

| 頁面 | 檔案 | 內容 |
| --- | --- | --- |
| 首頁 | `index.html` | 近期法會、本院簡介、最新相簿、佛學文章 |
| 法會行事曆 | `calendar.html` | 每月月曆（附農曆）與全年法會列表 |
| 活動相簿 | `gallery.html` | 法會照片相簿（可放大、左右滑動）與影片 |
| 佛學知識 | `dharma.html` | 依分類瀏覽的佛學文章 |

## 平常要更新內容，只需要改 `data` 資料夾

| 想更新的內容 | 要改的檔案 |
| --- | --- |
| 院名、地址、電話、開放時間、測試版提示 | `data/site.js` |
| 法會日期、時間、地點、每月例行共修 | `data/events.js` |
| 相簿照片 | 上傳到 `相簿` 資料夾（自動建立相簿） |
| 影片 | `data/albums.js` 的 YouTube 播放清單 |
| 佛學文章 | `data/articles.js` |

每個檔案最上面都有中文說明，照著複製一個區塊、修改文字即可。
農曆日期由網站自動換算，不用另外填。

### 在 GitHub 網頁上直接修改

1. 打開存放庫，點進要改的檔案（例如 `data/events.js`）。
2. 點右上角的鉛筆圖示（Edit this file）。
3. 修改文字，只改引號裡面的內容，引號和逗號要保留。
4. 改好後按綠色的「Commit changes...」，再按一次「Commit changes」。
5. 等一兩分鐘，重新整理網站就會看到更新。

### 上傳法會照片

1. 在電腦上建立資料夾，名稱用「日期 法會名稱」，例如 `2027-02-13 玉皇大帝聖誕`，把照片放進去。
2. 打開存放庫的 `相簿` 資料夾，按「Add file」→「Upload files」，把整個資料夾拖進去，按「Commit changes」。
3. 3～5 分鐘後網站就會出現新相簿。GitHub 會自動縮小照片、轉正方向、移除拍攝地點資訊（`tools/build_albums.py`）。

詳細說明在 `相簿/使用說明.txt`。

### 影片

影片上傳到 YouTube，加進古亭院的播放清單，再把播放清單網址貼到 `data/albums.js` 的 `VIDEO_PLAYLIST`。
之後加進播放清單的影片，網站會自動顯示。

## 範例內容

目前所有法會、相簿、文章、地址電話都是**範例**，網頁上會標示黃色「範例」字樣。
換成真實資料時，把該筆資料裡的 `sample: true` 那一行刪除，「範例」標示就會消失。
正式上線時，把 `data/site.js` 的 `testNotice` 改成 `""`，頁面上方的測試版提示就會隱藏。

## 在自己電腦上預覽（工程人員用）

直接用瀏覽器打開 `index.html` 即可，或在資料夾內執行 `python3 -m http.server` 後開啟 <http://localhost:8000>。

## 改完看不到新內容？

瀏覽器會暫存舊版網頁（GitHub Pages 約保留 10 分鐘）。可以按 `Ctrl + F5`（Mac 按 `Cmd + Shift + R`）強制重新整理。
工程人員修改 CSS 或 JS 後，請把各頁 HTML 裡 `?v=11` 的數字加 1，讓所有人的瀏覽器都抓新版。
