工作人員登入

本系統含信徒個人資料，僅限寺方工作人員使用。請輸入姓名與密碼；沒有帳號請洽管理者建立。

新增帳號（管理者用）

輸入新人員的姓名，取得登入 Email，再到 Firebase 後台 → Authentication → 使用者 → 新增使用者，貼上這個 Email 並設定密碼（至少 8 個字元）。

信徒報名紀錄查詢

僅支援姓名關鍵字查詢（可輸入完整姓名或姓氏），可另外選擇法會類別縮小查詢範圍

匯出所有報名資料（不限查詢結果，含歷史資料＋線上報名資料）

請輸入姓名開始查詢
可輸入完整姓名或姓氏
資料管理（僅管理員）

一、匯入歷史資料（舊版 Google 試算表的資料）

方式 A：貼上舊版查詢系統的 Apps Script 網址（結尾是 /exec），按「從網址匯入」，系統會直接把全部歷史資料抓進來。
方式 B：選擇歷史資料的 Excel／CSV 檔（欄位：年度、法會名稱、報名者姓名、電話、陽上人、項目、地址、費用、備註、收款狀態、照片、編號；每個工作表若沒有「法會名稱」欄，會用工作表名稱代替）。
重新匯入會「取代」全部歷史資料，不影響線上報名資料。

二、更新法會報名平台的線上報名資料

方式 A（建議）：直接從法會報名平台抓取最新資料。輸入您在法會報名平台的姓名與密碼（帳號需為啟用中的工作人員），按「從法會報名平台更新」。密碼只用這一次，不會儲存，抓完會自動登出法會報名平台。

方式 B：到法會報名平台後台，按「匯出資料備份（下載檔案）」，把下載的 .json 檔選進來。

兩種方式都會「取代」上一次的線上報名資料（會換成法會報名平台目前的完整資料）。

三、新增工作人員帳號

輸入志工姓名與預設密碼，按「新增帳號」就會建立並直接啟用。志工登入後可按上方「修改密碼」自行更改。

（舊方法）產生登入 Email，到 Firebase 後台手動建立

四、工作人員帳號啟用

工作人員第一次登入後會出現在下面（顯示「待啟用」），管理員按「啟用」後對方才看得到資料。不認識的名字請不要啟用。
